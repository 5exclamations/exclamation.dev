# EXCLAMATION — сайт студии разработки

## Проект

Сайт студии разработки **EXCLAMATION**, Баку. Один длинный лендинг с полным
описанием услуг, процесса, кейсов и формой заявки.

Продакшн-домен: `exclamationdev.com` (см. `CNAME`).

## Языки

Три языка: **азербайджанский (основной)**, русский, английский.

> Внимание: в текущем коде основным по факту является русский —
> `translations.js` начинается с `window.siteLanguageOrder = ["ru", "az", "en"]`,
> и при отсутствии сохранённого значения выбирается первый элемент. При
> переезде на Astro основным нужно сделать `az`.

## Текущее состояние (подлежит замене целиком)

Статический сайт без сборки, деплой через GitHub Pages:

- `index.html` — вся разметка и весь JS инлайном (~77 KB). Секции:
  `hero`, `services`, `why`, `who`, `advantages`, `process`, `cases`, `trust`,
  `tech`, `contact`, `faq`, `finalcta`.
- `style_dark.css` / `style_light.css` — две полные копии стилей. Переключение
  темы = включение/выключение `<link disabled>` (`#theme-dark` / `#theme-light`).
- `translations.js` — `window.siteTranslations` с ключами `ru` / `az` / `en`
  (~77 KB). Перевод применяется на клиенте после загрузки, язык хранится в
  `localStorage` под ключом `nexora-language`, тема — `nexora-theme`.
- `pics/` — скриншоты кейсов: `crm`, `ERP`, `merk`, `mobile`, `website`.
- `exclamation-bimi-logo.svg` — BIMI-логотип.

Кейсы на странице (`data-case-id`): `crm`, `bookingpro`, `erp`, `medapp`,
`ecommerce`, `autoflow`. Лайтбокс со скриншотами собирается из `pics/`.

Внешние зависимости, которые надо учесть при переносе:

- Google Fonts: `Unbounded` (300/400/600/700/900), `Manrope` (300/400/500/600).
- Форма заявки: Formspree — `https://formspree.io/f/mdayvkzp`, прогрессивное
  улучшение через `@formspree/ajax` с unpkg.
- Контакты: `tel:+994706565909`, `info@exclamationdev.com`,
  `t.me/exclamationdev`, `wa.me/994702054171`.

Наследие в именовании: префикс `nexora-` в ключах `localStorage` — от старого
названия. При переписывании заменить на `exclamation-`.

## Целевой стек

- **Astro**, статическая сборка (`output: 'static'`).
- **Обычный CSS** с кастом-пропертями и `@layer`.
- **Tailwind не использовать. React не использовать.**
- Тема (светлая/тёмная) — один набор стилей, переключение через кастом-проперти
  на `:root`, а не два отдельных css-файла.
- i18n — средствами Astro (маршруты по языкам, статическая генерация), а не
  подстановкой строк на клиенте.

## Деплой

**Cloudflare Pages** из этого же репозитория. GitHub Pages отключается после
переезда.

## Правила работы

- **Перед тем как сказать «готово» — открой страницу через playwright и
  посмотри на неё.** Не отчитываться об успехе по факту успешной сборки.
- Проверять все три языка и обе темы, а не только дефолтную комбинацию.
- `refs/` — папка со скриншотами референсов, в git не попадает.
