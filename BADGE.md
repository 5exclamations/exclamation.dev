# BADGE — the attribution mark for client products

`DEVELOPED BY ! EXCLAMATION`, linking to the English home page. One lockup,
one set of files, generated by `npm run badge` from the site's own fonts and
tokens. Everything below quotes those files; nothing here is retyped by hand.

Built assets live in `public/badge/` and ship with the site, so every one of
them is also a public URL under `https://exclamationdev.com/badge/`.

---

## 1. Pick the form, not the colour

| Situation | Use |
| --- | --- |
| A web page you can edit the HTML of | **the inline snippet** — `public/badge/embed.txt` |
| A page where an extra request is fine and the ground is light | `<img src=".../exclamation-light.svg">` |
| …and the ground is dark | `exclamation-dark.svg` |
| …and the product follows the viewer's OS theme | `exclamation-auto.svg` |
| Native app, README, deck, PDF, anything that cannot draw an SVG | the PNGs, `@2x` / `@3x` included |

**The inline snippet is the default.** It carries the two words as outlines,
so it needs no font, makes no request, survives a strict CSP, and takes the
host's own text colour — which is why it looks right on a white footer, on a
bone one and on a navy one without a single edit.

## 2. The inline snippet

```bash
cat public/badge/embed.txt
```

Paste it verbatim into the client's footer. It is one `<a>` wrapping one
`<svg>`; there is nothing in it to configure. Remote machines can fetch the
same string:

```bash
curl -s https://exclamationdev.com/badge/embed.txt
```

The mark's colour is the one thing it exposes, for grounds where `#FF4A1E`
sits too hot:

```css
footer { --exclamation-accent: #b32e0a; }  /* ember, for light grounds */
```

## 3. The hosted image

```html
<a href="https://exclamationdev.com/en/?ref=badge" target="_blank" rel="noopener">
  <img src="https://exclamationdev.com/badge/exclamation-light.svg"
       alt="Developed by EXCLAMATION" height="24" width="316">
</a>
```

`height="24"` is the intended size; 20 is the floor at which the mono line
still reads. Always ship `width` beside it — the badge is 316 × 24 and an
unsized image reflows the footer while it loads.

`exclamation-auto.svg` switches on `prefers-color-scheme`, which is the
**viewer's OS**, not the host's background. It is right only for a product
that follows the OS itself; a light-only site serving it to a dark-mode
visitor gets a bone badge on a bone footer.

## 4. Markdown / README

```markdown
[![Developed by EXCLAMATION](https://exclamationdev.com/badge/exclamation-light.svg)](https://exclamationdev.com/en/?ref=badge)
```

GitHub serves READMEs on both themes, so prefer the PNG pair with a
`<picture>` block when the repo is public and the theme matters.

## 5. What must not change

- **The link is `https://exclamationdev.com/en/?ref=badge`.** English home
  page, always — the badge is read by people who do not have Azerbaijani. The
  `ref` is how attribution traffic is told apart from search, and it survives
  the referrer being stripped.
- **The two words are English and stay English.** One badge, one rendering, on
  every client product regardless of that product's language.
- **No recolouring beyond `--exclamation-accent`.** Text is `currentColor` by
  design; the mark is signal or ember, and nothing else.
- **No re-tracing, no re-spacing, no cropping the mark out of the lockup.** If
  a size or a variant is missing, regenerate it with `npm run badge` — do not
  edit an SVG by hand and do not let a model retype the path data.

## 6. Regenerating

```bash
npm run badge
```

`scripts/badge.ts` lays the lockup out with satori, using `instanceFont` on
the site's own woff2 — the same faces the pages load, pinned to Geologica 500
and JetBrains Mono 400, converted to outlines. It writes all four SVGs, six
PNGs and `embed.txt`, and it is the only thing allowed to write them.

Geometry, if it ever has to be rebuilt from scratch: mono label at 18px /
0.12em in `--fg-muted`, 20px gap, the bar-and-dot mark at the header's 17:4:4
proportions and 1.2× the wordmark's size, 17px gap, wordmark in display 500 at
26px / 0.16em. Content box 435 × 33, shipped at 316 × 24.
